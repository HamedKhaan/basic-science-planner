# برنامه‌ریز علوم پایه ۱۴۰۵ — نصب به‌صورت اپ اندروید

این پوشه یک **PWA قابل‌نصب** است. دو راه برای «اپ شدن» داری:

---

## راه ۱ (پیشنهادی، رایگان، سریع): نصب از کروم اندروید

1. همهٔ فایل‌های این پوشه را در یک ریپوی GitHub بگذار (حتماً `index.html` در ریشه باشد).
2. Settings → Pages → Deploy from branch → `main` / root
3. آدرس را در **Chrome اندروید** باز کن، مثلاً:
   `https://USERNAME.github.io/REPO_NAME/`
4. منوی ⋮ → **Install app** / **نصب برنامه** / Add to Home screen
5. آیکون روی صفحهٔ اصلی می‌آید و تمام‌صفحه مثل اپ باز می‌شود.

> فایل را مستقیم از دانلود (`file://`) باز نکن — نصب واقعی فقط روی HTTPS کار می‌کند.

---

## راه ۲ (فایل APK واقعی برای نصب مثل اپ فروشگاهی): PWABuilder

1. همان آدرس GitHub Pages را آماده کن (راه ۱ تا مرحله ۳).
2. برو به: https://www.pwabuilder.com
3. آدرس سایتت را وارد کن → Start
4. بخش **Android** → **Generate Package**
5. گزینهٔ **Google Play Package** یا **APK** را بگیر و دانلود کن.
6. روی گوشی فایل `.apk` را باز کن و نصب کن (ممکن است «نصب از منابع ناشناس» را روشن کنی).

این خروجی یک اپ اندرویدی واقعی است (TWA) که همان برنامه را با آیکون و نصب سیستمی اجرا می‌کند.

---

## ساختار فایل‌ها

- `index.html` — خود برنامه
- `manifest.webmanifest` — مشخصات نصب
- `sw.js` — کار آفلاین و کش
- `icons/` — آیکون ۱۹۲ و ۵۱۲

---

## به‌روزرسانی

هر بار `index.html` جدید را جایگزین کن و روی گوشی یک‌بار صفحه را رفرش کن (یا اپ را ببند و باز کن).
