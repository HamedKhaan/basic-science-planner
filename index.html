۱) اصول علمی

شواهد‌محور

اصل سیستم

خروجی یادگیری > ساعت مطالعه. هدف «خواندن زیاد» نیست؛ بازیابی، تست، تشخیص خطا، و تثبیت در حافظه بلندمدت است.

Retrieval Practice

بستن کتاب → گفتن/نوشتن/رسم از حافظه → چک → اصلاح. حس تسلط از بازخوانی اغلب کاذب است.

Spaced Practice

یک‌بار بلدم ≠ تا آزمون بلدم. امتیاز ۱–۵ فاصله بعدی را می‌سازد (سقف حدود ۶۰ روز).

Interleaving

مفاهیم شبیه → بخشی از تست‌ها ترکیبی. مبحث کاملاً جدید → اول متمرکز، بعد درهم.

۹۰ + ۲۰ (Ultradian)

کار عمیق حدود ۹۰ دقیقه؛ استراحت ۲۰ دقیقه‌ای فعال (نه اسکرول بی‌پایان). خواب شبانه پیوسته جداست.

انواع خطا

  • مفهومی: مدل ذهنی غلط → اصل + مثال متضاد
  • دانشی: واقعیت جا نیفتاده → فلش‌کارت کوتاه
  • تمایز: جدول مقایسه + تست ترکیبی
  • استدلال / صورت سؤال: تمرین خواندن سؤال
  • بی‌دقتی / زمان: چک‌لیست رفتار آزمونی
قانون Must روزانه: اهمیت آزمونی × ضعف فعلی × نزدیکی مرور. بلدی ولی تست ضعیف → تست+تحلیل. صف مرور سنگین → اول مرور. خواب بد → حجم را کورکورانه زیاد نکن.

۲) گردش کار روزانه

  1. صبح ۳ دقیقه: Mustها + ۱ مرور سررسید + بلوک فعلی
  2. اولویت: عقب‌افتاده مرور قبل از حجم جدید
  3. تمرکز: دکمه شروع تمرکز روی بلوک · تمام / ناقصِ مفید
  4. تست: تا هدف، نه لزوماً تا سقف نرم · غلط → دفتر خطا
  5. غروب: نتایج + در صورت نیاز پر کردن «فردا»
  6. انرژی کم: روز حداقلی یا بازیابی — پیوستگی > کمال

۳) بخش‌های برنامه

زمان (کارت‌های ۹۰+۲۰)
شب قبل در «فردا» پر کن. نوع + مبحث بنویس. همگام با Must. تیک = پیشرفت روز.
تمرکز
فقط بلوک فعلی + تایمر. بعد از رفرش قابل ادامه است.
Must / جلسات
۳ غیرقابل‌مذاکره. جلسات = واقعیت انجام‌شده.
دفتر خطا + بانک سؤال
همان روز ثبت کن. کارت بازیابی از اشتباه خودت.
صف مرور
بعد از بازیابی امتیاز ۱–۵. اول عقب‌افتاده، بعد سررسید.
شبیه‌ساز
هفته‌ای ۱–۲ بار نزدیک شرایط واقعی + کالبدشکافی غلط‌ها.
Heatmap / عادت / هفته هوشمند
Must از قرمزها. ۴ عادت حیاتی. برنامه ۷روزه از فاز+ضعف.
هدف معکوس / PDF / تنظیمات
کیفیت پوشش نه همه ۲۰هزار تست. سختی هفته و روز بازیابی.

۴) الگوریتم مرور (خلاصه)

الهام از SM-2/Anki: interval (فاصله روز) + ease (سختی کارت) + تعداد تکرار موفق.

  • ۱–۲ سخت → فاصله ۱–۲ روز، ease پایین
  • ۳ متوسط → رشد ملایم فاصله
  • ۴–۵ آسان → فاصله بلندتر (سقف ~۶۰ روز)

جزئیات کامل در گفتگو/یادداشت‌های قبلی؛ اینجا فقط برای تصمیم سریع روزانه‌ات کافی است.

۵) سناریوها

صف مرور سنگین: ۱–۲ روز فقط مرور + تست کم.

خواب بد / کیفیت ≤۲: هدف خودکار سبک می‌شود → حداقلی یا بازیابی.

نزدیک آزمون: سختی فشرده، شبیه‌ساز بیشتر، قرمزهای Heatmap.

مریضی / امتحان دانشگاه: سختی آرام + حفظ عادت‌های حیاتی.

۶) ضدالگوها

  • خواندن زیاد بدون بازیابی و تست
  • ثبت نکردن خطا «بعداً»
  • رد شدن از سقف نرم بدون تحلیل
  • صفر کردن روز به‌خاطر یک بلوک ناقص
  • فقط درصد شبیه‌ساز بدون کالبدشکافی
  • عوض کردن برنامه هر روز به‌جای اجرای ۸۰٪ همان برنامه

قانون طلایی: هر روز حداقل یک بازیابی واقعی + ثبت/مرور خطا در صورت تست + خواب قابل‌قبول. برنامه برای انسان است، نه ربات.
