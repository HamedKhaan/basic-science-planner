## اجرا و نصب

آدرس عمومی برنامه:

https://hamedkhaan.github.io/basic-science-planner/

در مرورگرهای سازگار، از منوی مرورگر گزینهٔ **Install app** یا **Add to Home screen** را انتخاب کنید. برنامه پس از یک بار باز شدن با اینترنت، برای استفادهٔ آفلاین نیز آماده می‌شود.
