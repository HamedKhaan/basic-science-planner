# علوم پایه — یادگیری (PWA)

نسخهٔ نصب‌پذیر وب برنامهٔ علوم پایه.

## نسخهٔ وب

آدرس عمومی برنامه:

https://hamedkhaan.github.io/basic-science-planner/

در مرورگرهای سازگار، از منوی مرورگر گزینهٔ **Install app** یا **Add to Home screen** را انتخاب کنید.

## نسخهٔ اندروید APK

پس از هر تغییر در پوشهٔ `app`، GitHub Actions فایل APK را می‌سازد. برای دریافت آن به بخش **Actions** مخزن بروید، اجرای موفق **Build Android APK** را باز کنید و از بخش **Artifacts** فایل `olum-paye-apk` را دانلود کنید.

این APK یک بستهٔ سبک اندرویدی است که برنامهٔ وب را در WebView امن باز می‌کند؛ بنابراین برای اولین اجرا به اینترنت نیاز دارد.

## انتشار

این پروژه با GitHub Pages از شاخهٔ `main` و مسیر ریشه منتشر می‌شود.
